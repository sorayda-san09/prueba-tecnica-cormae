# Prueba técnica - Grupo Cormae 

## Instrucciones para ejecutar
1. Asegúrate de tener Python instalado junto con las librerías necesarias ("pandas" y "openpyxl").
2. Coloca el archivo de entrada con los datos en la misma carpeta.
3. Ejecuta el script en la terminal con el siguiente comando:
   python script.py

# Qué fue lo mas difícil 
Para mi lo más dificil fue la incongruencia en las CLABES por lo cual
se tuvo que reforzar la lectura de la columna para la validación, 
lo que permitio generar mensajes de errores claros.
